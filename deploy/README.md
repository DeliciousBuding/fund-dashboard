# Deploy — build & run

Single-container image: Go API + MCP backend (static binary), SQLite persistence.
The web UI is a separate frontend repo — this image is API-only.

## Build the image

```bash
docker build -f deploy/Dockerfile -t fund-dashboard:local .
```

The `deploy/Dockerfile` is multi-stage: `golang:1.26-alpine` compiles the backend,
and the final `alpine:3.20` image runs as an unprivileged `fund` user with
`EXPOSE 8765`.

## Run with Docker Compose (production)

`deploy/docker-compose.yml` runs the published image with SQLite persistence and
secrets read from a `.env` file:

```bash
cp .env.example .env
# edit .env: set MCP_API_KEY (openssl rand -hex 32), FUND_EDGE_KEY for frontend write routes
docker compose -f deploy/docker-compose.yml up -d
```

The compose file mounts `./data` for the database, runs as the unprivileged
`fund` user, and includes a `/api/health` healthcheck. `.env`, `data/` and all
`*.db*` files are git-ignored.

## Run locally (bare docker run)

```bash
docker run --rm -p 8765:8765 \
  -v "$(pwd)/data:/app/data" \
  -e FUND_DB_PATH=/app/data/fund.db \
  -e FUND_HTTP_ADDR=0.0.0.0:8765 \
  -e MCP_API_KEY=dev-only-key \
  fund-dashboard:local
```

## CI compose

`deploy/docker-compose.ci.yml` is used by GitHub Actions `smoke-e2e` to boot the
container against a seeded SQLite database (`deploy/ci-data`, generated by
`scripts/seed-ci-db.sh`).

## Environment variables

See `.env.example` for the full list. Required in
production: `MCP_API_KEY` (admin + MCP operator), `PUBLIC_MCP_KEY` (MCP analyst,
read-only), `FUND_EDGE_KEY` (frontend mutation key injected by the edge proxy).
All are placeholders in `.env.example`; real values must never be committed.
