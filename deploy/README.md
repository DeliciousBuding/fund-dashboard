# Deploy — build & run

Single-container image: Go backend (static binary) + React SPA, SQLite persistence.

## Build the image

```bash
docker build -f deploy/Dockerfile -t fund-dashboard:local .
```

The `deploy/Dockerfile` is multi-stage: `golang:1.26-alpine` compiles the backend,
`node:24-alpine` builds the SPA, and the final `alpine:3.20` image runs as an
unprivileged `fund` user with `EXPOSE 8765`.

## Run locally

```bash
docker run --rm -p 8765:8765 \
  -v "$(pwd)/data:/app/data" \
  -e FUND_DB_PATH=/app/data/fund.db \
  -e FUND_STATIC_DIR=/app/web \
  -e FUND_HTTP_ADDR=0.0.0.0:8765 \
  -e MCP_API_KEY=dev-only-key \
  fund-dashboard:local
```

## CI compose

`deploy/docker-compose.ci.yml` is used by GitHub Actions `smoke-e2e` to boot the
container against a seeded SQLite database (`deploy/ci-data`, generated by
`scripts/seed-ci-db.sh`).

## Environment variables

See `.env.example` at the repository root for the full list. Required in
production: `MCP_API_KEY` (admin + MCP operator), `PUBLIC_MCP_KEY` (MCP analyst,
read-only), `FUND_EDGE_KEY` (SPA mutation key injected by the edge proxy).
All are placeholders in `.env.example`; real values must never be committed.
